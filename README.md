## コードの使い方

Pythonのインストール方法は、第1回の動画で解説しています。

### 方法1: コードを見ながら自分で入力する(おすすめ)

上の表から各回のフォルダを開き、動画と一緒に入力してみましょう。
自分の手で書くと、書き方が身につきやすくなります。

### 方法2: ファイルをまとめてダウンロードする

1. このページの緑色の **Code** ボタンをクリックします。
2. **Download ZIP** をクリックします。
3. ダウンロードしたZIPファイルを展開します。
4. 使いたい回のフォルダをVS Codeで開きます。

### プログラムの実行

VS Codeのターミナルで、次のように入力します。

```powershell
python hello.py
```

## うまく動かないとき

- かっこや引用符が、全角になっていないか確認してください。
- ファイルを保存してから実行しているか確認してください。
- ターミナルで `ls` と入力し、実行したいファイルがあるか確認してください。
- エラーメッセージは、一番下の行から読んでみてください。
